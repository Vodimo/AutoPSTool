# AutoPSTool 手动测试清单

> 用途：逐一核对头脑风暴设计（2026-06-26 spec）与历轮反馈修复的全部功能。
> 建议流程：双击 `start.bat` 启动，用 `tests/fixtures/cats_11.png`（11 只猫）作为测试图。
> 标注说明：〔spec·N站〕= 头脑风暴第 N 站约定；〔反馈〕= 后续使用反馈修复项。

## 一、导入与工作区〔spec·1站〕

- [ ] **1.1 多选导入**：点「📥 导入」一次框选多张图 → 逐张显示抠图进度，全部主体追加到画布（不清空已有零件）
- [ ] **1.2 抠图质量**：11 只猫全部分离为独立零件，白猫内部无透明洞，边缘干净
- [ ] **1.3 滚轮缩放**：以鼠标位置为锚点缩放，范围 10%–800%，右下角显示缩放百分比
- [ ] **1.4 空格平移**：按住空格拖动画布平移；松开恢复正常选择
- [ ] **1.5 中键平移**：按住鼠标中键拖动平移（不触发浏览器自动滚动圆点）〔反馈〕
- [ ] **1.6 适应视图**：点「⤢ 适应视图」→ 纸框和所有零件完整可见、居中
- [ ] **1.7 纸张预设**：A4/A3/A5/Letter 一键切换，纸框（白色矩形）尺寸随之变化
- [ ] **1.8 自定义纸张**：选「自定义」后宽高可输入，mm/px 单位切换数值正确换算
- [ ] **1.9 改纸张零件不动**：改纸张尺寸后已摆放零件位置不变，露到框外的零件照常显示
- [ ] **1.10 平移/缩放后点选准确**：缩放平移视图后点击零件，选中的就是点的那个（无错位）〔反馈〕

## 二、白边 / 刀模线 / 平滑〔spec·2站〕

- [ ] **2.1 白边实时调**：拖白边滑块，所有零件白边宽度实时变化；数值框与 mm/px 单位联动
- [ ] **2.2 刀模线实时显示**：画布上每个零件外缘有洋红 #FF00FF 刀模线，随拖/缩/白边实时更新
- [ ] **2.3 刀模线平滑无锯齿**：放大看刀模线是平滑曲线（potrace 矢量），不是像素阶梯
- [ ] **2.4 平滑滑块**：0=现状；调到 2–3 后白边轮廓的直边折线感消失，变圆润〔反馈〕
- [ ] **2.5 白边居中重算**：调白边时零件绕自身中心胀缩，不向右下漂移

## 三、修补画笔〔spec·2站〕

- [ ] **3.1 进出模式 + 画笔光标**：「🖌️ 修补」或 B 键进出；鼠标变成跟随的圆形画笔（加=绿/擦=红）；模式内零件不可拖动；Esc 退出〔反馈〕
- [ ] **3.2 加/擦切换**：工具栏「加/擦」下拉；加=绿色预览，擦=红色预览
- [ ] **3.3 笔刷大小**：滑块调整，涂抹时预览线粗细一致
- [ ] **3.4 实时生效**：每一笔松手后立即应用并看到结果（无需确认），零件即时更新〔反馈〕
- [ ] **3.5 逐笔撤销**：Ctrl+Z 可逐笔回退修补；Esc 退出修补模式〔反馈〕
- [ ] **3.6 涂抹位置精准**：笔迹落点就在鼠标处（不偏移）〔反馈〕
- [ ] **3.7 擦桥分件**：用「擦」画断两个相连主体之间的桥 → 应用后分裂成两个独立零件
- [ ] **3.8 修补不跳位**：应用后零件停留原位（图像内容严格对齐）〔反馈〕
- [ ] **3.9 修补后仍参数化**：修补产物的白边仍随白边滑块实时变化
- [ ] **3.10 旋转零件拦截**：对旋转过的零件涂抹 → 提示先按 L 归零
- [ ] **3.11 缩放零件笔径一致**：对放大过的零件涂抹，笔迹在屏幕上的粗细与设定一致

## 四、选择 / 变换 / 锁角〔spec·3站〕

- [ ] **4.1 逐像素点选**：点零件周围的透明区域不会选中它；两零件靠近时点到谁的主体/白边就选谁〔反馈〕
- [ ] **4.2 框选多选**：空白处拖框可多选；多选整体拖动；「🗑️ 删除」删除多选；多选操作可撤销
- [ ] **4.3 等比缩放**：选中零件只有四角手柄（无中边手柄），拖角始终等比缩放
- [ ] **4.4 旋转即锁角**：拖旋转手柄后零件自动锁角，描边变洋红**且不选中时也常显**〔反馈〕
- [ ] **4.5 锁角浮标签**：选中锁角零件浮现「📌 角度已锁 · 点击解除」，点击后角度归零（绕中心，不跳位）
- [ ] **4.6 L 键解锁**：选中锁角零件按 L → 同上解锁归零
- [ ] **4.7 快捷键不干扰输入**：光标在任一输入框内时按 C/B/L/空格不触发对应功能

## 五、切割〔spec·3站〕〔反馈·多轮重做〕

- [ ] **5.1 进出模式**：「✂️ 切割」按钮或 C 键进出；横幅按阶段提示（选目标 → 画线）
- [ ] **5.2 点选目标**：点击零件设为切割目标（高亮）；旋转/锁角零件被拒并提示
- [ ] **5.3 画线不歧义**：选定目标后，左键点击**任何位置**（包括其他零件身上）都是画线起点，不会误换目标
- [ ] **5.4 两击画线 + 实时跟随**：第一击定起点后，虚线终点**实时跟随鼠标**（上下左右任意方向）；第二击定终点
- [ ] **5.5 暂存可调**：线定型后出现两个端点圆手柄 + 「确认切割/取消」浮动条；可拖整线平移、拖端点单独调整
- [ ] **5.6 确认/取消**：「✂️ 确认切割」或 Enter 执行；「取消」或 Esc 放弃这条线可重画
- [ ] **5.7 Esc 三级回退**：有线时 Esc=取消线；无线有目标时 Esc=重选目标；都没有时 Esc=退出模式
- [ ] **5.8 切完两侧分开**：切出的两块沿切割线法线方向分居两侧（不重叠在原地）
- [ ] **5.9 切割块仍参数化**：切出的块白边仍随白边滑块实时变化〔反馈〕
- [ ] **5.11 切口平直无白边**：切割边缘笔直、两端锋利；切口处主体直抵刀模线，无白边、无出血延伸〔反馈〕
- [ ] **5.12 缩放零件切割**：放大过的零件切完，两块保持同样放大倍数〔反馈〕
- [ ] **5.13 确认后自动退出**：切割完成自动退出切割模式，零件恢复可拖动

## 六、排版〔spec·4站〕

- [ ] **6.1 真实进度**：点「🧩 整理排版」，进度条随零件逐个放置递进（不是卡住再跳 100%）〔反馈〕
- [ ] **6.2 紧凑排版**：11 只猫在 A4 内全部放下，自由零件被自动旋转塞紧，无重叠
- [ ] **6.3 锁角保角**：先把某零件旋转锁角，排版后它保持该角度只挪位置
- [ ] **6.4 精度滑块**：1（快）→ 24（极致）连续可调；高精度更紧但更慢
- [ ] **6.5 间距生效**：间距调大（如 5mm）重排 → 零件间隙明显变大；mm/px 单位换算正确
- [ ] **6.6 统一缩放**：小纸张（如 A5）放不下时勾选「统一缩放」→ 全部零件按同一比例缩小后全部放下

- [ ] **6.8 排版可撤销**：Ctrl+Z 恢复排版前的位置角度

## 已知偏差（设计时已声明，供知情核对）

- **排版引擎**：spec 原定 SVGnest（浏览器内遗传算法），实际为服务端**旋转感知 Bottom-Left-Fill**（shapely）。功能目标（锁角/自由旋转、精度/间距、统一缩放、异步进度）均已覆盖；`nesting` 模块边界未变，未来可整体替换为 SVGnest。
- **旋转零件的切割/修补**：按约定拦截提示（先归零再操作），不支持带角度直接编辑。
- **导出格式**：仅 PNG（spec 本期约定）；矢量刀模路径等数据已在后端备齐，SVG/PDF 留待后续。
