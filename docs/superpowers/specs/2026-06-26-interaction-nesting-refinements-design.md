# AutoPSTool 交互与排版增强 — 设计文档

- 日期：2026-06-26
- 状态：已通过用户逐站确认，待写实施计划
- 性质：**在现有 `app/` + `web/` 架构上增量改造**（五模块架构不变，在其上扩展）

## 背景与目标

v1 已能「导入白底图 → 抠图分离 → 白边/刀模 → 拖/缩/切 → 排版 → 导出 PNG」。本次按真实工作流逐站打磨交互与质量，使其达到「专业、顺手、稳定」。所有改动是对现有模块的扩展，不重写架构。

涉及的现有模块：`geometry.py` / `segmentation.py` / `part_builder.py` / `nesting.py` / `exporter.py` / `server.py` / `web/*`。新增：`vendor/potrace/`（矢量化二进制）、矢量化与 SVGnest 集成、撤销/重做、进度反馈。

## 全局规范（跨站）

- **单位 mm/px 贯穿**：白边、出血、间距、画布尺寸的数值输入均支持 mm 与 px 两种单位，内部统一 `PIXEL_RATIO=10`（1mm=10px）换算。
- **进度反馈**：所有会让用户等待的操作（抠图、首次加载模型、potrace 矢量化、排版、改白边/出血重算、统一缩放搜索、导出）统一给进度提示（进度条/转圈 + 文字状态），异步、不卡界面。
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Y`，覆盖所有操作，一次完成的手势=一步，历史深度封顶（如 50 步）。
- 代码注释/日志中文；刀模线洋红 `#FF00FF`；物理常量只在 `geometry.py`。

## 第 1 站 · 导入 + 工作区

**导入**
- 支持**一次多选**图片，批量抠图，所有主体**追加**到当前画布（不清空已有零件）。
- 白底容差由 AI 抠图兜底，无需用户设置（背景可以不是纯白）。

**工作区与纸框（交互模型变更）**
- 画布从「fabric 画布 = 那张纸」改为「**大工作区**里画一个**纸框（可印刷区）**」。
- 工作区：**滚轮缩放 + 空格拖动平移**，理论无限大（PS/AI 式）。
- 零件可放在纸框内或纸框外，**始终可见**；改纸张尺寸时零件**保持位置**，露到框外也照常显示（不再被裁掉不显示）。

**纸张尺寸**
- **预设 + 自定义**：常用尺寸一键选，特殊尺寸手动填宽/高。
- 单位 mm/px；**随时可改**，改后已排零件保持位置。

## 第 2 站 · 抠图 / 白边 / 刀模

**抠图**：维持 rembg（u2netp）+ `clean_edges` → `separate_components` → `fill_holes`。

**白边宽度**
- **全局统一可调**（不做单零件），数值输入（mm/px）。
- 改动**尽量实时反馈**：选中零件即时重算；全部零件防抖（松手后）重算。
- 重算 = 重新膨胀生成白边掩膜 + 重新矢量化刀模线。

**刀模线矢量化（消锯齿）**
- 刀模轮廓由像素阶梯改为 **potrace 真矢量贝塞尔曲线**：把零件的刀模掩膜喂给 `vendor/potrace/potrace.exe`（子进程，输出 SVG），解析出贝塞尔路径。
- 白边外缘按这条平滑曲线对齐渲染；切出来的每一块也走 potrace（消除切割后碎块的边缘锯齿），但**切口那条直线保持笔直**（不让 potrace 磨圆，保证拼回对齐）。
- **画布上实时显示洋红刀模线**（当前前端只在导出时画，需补：每个零件叠一条洋红刀模轮廓，随拖/缩/旋转/改白边实时更新）。
- potrace 依赖：把 `potrace.exe`(157K) + `libpotrace-0.dll`(42K) + `zlib1.dll`(125K) 共 ~324KB 收进仓库 `vendor/potrace/`（已验证仅此 3 文件即可在无 msys64 的 PATH 下跑出平滑贝塞尔 SVG；其余 `api-ms-win-crt-*` 为 Windows 自带 UCRT）。

**手动修补画笔**
- 选中零件后，用**画笔在其 mask 上「加一笔 / 擦一笔」**，松手后重算白边+刀模线。
- 用途：修正抠图「多扣/少扣」；擦断两个相邻主体之间相连的「桥」即可把它们分成两个独立零件（覆盖「该分没分开」的需求）。

## 第 3 站 · 交互：拖 / 缩 / 旋转 / 切割 + 撤销

**缩放**：拖角等比缩放，**始终锁宽高比**；不需要数值输入。

**旋转（锁角 / 自由角模型）**
- 现状问题：fabric 默认可旋转，但 `nest`/导出/前端请求全程忽略 `rotation` → 旋转后排版重叠、导出错位。本次**打通旋转**到排版碰撞与导出。
- **手动转 = 自动锁角**：拖旋转手柄即把该零件置为「锁角」。
- 锁角零件视觉标记：选中框/手柄用**洋红「锁角色」** + 角上**图钉/锁图标 📌**（与自由角的普通蓝色区分）。
- **解除锁角**：选中时浮出小标签「📌 角度已锁 · 点击解除」，点击或按 `L` 切换回自由角。
- 排版时：锁角零件保角度只挪位；自由角零件由程序旋转塞紧。

**切割（分件，PS 式预览-确认流程）**
- `C` 快捷键（及按钮）进/出切割模式。
- 切割模式中**必须选中一个零件**，切割只作用于当前选中零件；**单击另一个零件 = 把切割目标换成它**。
- 在选中零件上**拖一条直线**：全程**只画实时预览线、不移动零件**；显示**预览**（切割线 + 切完两块按出血略微错开的示意）。
- **`Enter` 确认才真正执行**这一刀（可反复重画直到满意）；`Esc` 取消。确认完成后退出切割模式。
- **出血量全局可调**（数值 mm/px）。
- 切完两块**自动错开一点**摆放；两块各自走 potrace 矢量化（切口直线保持笔直）。
- 直线切割即可，不做折线/曲线。

**撤销 / 重做**
- `Ctrl+Z` / `Ctrl+Y`，覆盖所有操作（移动/缩放/旋转/切割/删除/导入/改白边/改出血/排版/锁解角度）。
- 一次完成手势 = 一步；快照式（零件集合 + 各自位置/缩放/角度/锁定状态），零件图像/掩膜不可变可复用，快照轻；历史深度封顶。

## 第 4 站 · 排版

**引擎：SVGnest（浏览器内）**
- NFP（No-Fit-Polygon）真形状 + 遗传算法，带旋转；纯 JS、零安装、零编译（已验证 pynest2d/nest2D 在 PyPI 无法安装，C++ 源码编译风险高，故不走 Python 内核）。
- 收进项目并适配；遗传算法逐代优化，后台跑、显示进度、可随时取当前最优。
- 每个零件的允许旋转可单独配置：**锁角零件只给其当前角度（1 个），自由角零件给一圈角度** → 实现锁/自由模型。
- 容器 = 纸框；零件多边形用矢量刀模轮廓。

**两个连续可调滑块**
- **排版精度**：连续，从「快/粗」到「慢/最省纸」，内部映射为（旋转角度密度 + 遗传算法迭代/时间预算）。跑得越久越紧。
- **零件间距**：连续，数值 mm/px，控制零件间最小安全间距。

**统一缩放开关**
- 关（默认）：按当前大小排；放不下的零件**自然留在纸框外**（工作区里），不强塞。
- 开：排版时把**所有零件按同一比例**整体缩放，在不超出纸框前提下最大化利用率（保持相对大小）。实现 = 在 SVGnest 外套一层对全局缩放比例的搜索（按面积估初值，再微调到「刚好放下且最满」）。

**异步**：排版后台跑、进度条、跑完自动更新画布。

## 第 5 站 · 导出

- v1 **只导单张 PNG**（图片 + 白边底 + 洋红刀模线），与现状一致。
- **内部把未来可能要的数据全部备齐**：每个零件的 potrace 矢量刀模路径、图片层、变换（位置/缩放/角度）、纸张尺寸/单位。这样以后加 SVG / PDF / 专色 / 刀模单独图层只是「多写一个导出格式」，不动数据结构（延续「图片层 / 矢量刀模层分离」原则）。
- **纸框外的零件不导出**，但**导出前弹提示**（如「有 N 个零件在纸框外，不会被导出，是否继续？」）。

## 数据模型影响

`Part` 扩展/明确以下字段语义（增量，非重写）：
- `rotation`：真正参与排版碰撞与导出（之前是死字段）。
- 新增 `locked_angle: bool`（锁角/自由角）。
- 新增 `dieline_path`：potrace 矢量刀模路径（贝塞尔），与现有 `contour` 并存或替代用于显示/导出。
- 全局会话状态新增：纸张尺寸、单位、白边、出血、间距、精度、统一缩放开关。

## 非目标（本次不做）

- SVG/PDF/专色导出（仅备数据，不实现导出按钮）。
- 折线/曲线切割。
- 单零件白边、零件位置「钉死」（锁的只是角度）。
- 多页排版。

## 验收标准

- 多选导入多张白底图能批量抠出主体并追加到工作区。
- 纸框可改尺寸、缩放平移；零件超框仍显示。
- 白边宽度数值可调、实时反馈；刀模线在画布上平滑无锯齿、洋红显示。
- 手动画笔能修正多扣/少扣并能擦桥分主体。
- 手动旋转自动锁角且有标记、可解除；锁角排版保角、自由角排版自动转；旋转后导出位置正确。
- 切割走「选中→预览→确认」流程、画线不动零件、出血可调、碎块边缘平滑。
- 撤销/重做覆盖所有操作。
- SVGnest 排版后台跑、精度/间距连续可调、统一缩放开关有效、放不下的留框外。
- 导出 PNG 与现状一致；框外零件不导出且有提示。
- 所有耗时操作有进度提示。
