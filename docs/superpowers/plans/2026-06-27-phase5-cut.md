# Phase 5 · 切割流程重做 Implementation Plan

> 执行：subagent-driven。范围:切割(分件)的完整重做。**不碰 nesting 自动旋转(Phase8)**、不碰 undo(Phase7)。

**Goal:** 把切割从占位变成可用:`C` 键进/出切割模式;选中一个零件后在其上**拖一条直线画预览线**(全程不移动零件);松手显示**两块结果预览**(带出血、略错开);`Enter` 确认生效、`Esc` 取消;出血量全局可调(mm/px)。参数化零件按**当前白边**实体化后再切,产出两块**固定零件**(切口平直冻结)。

## 锁定决策
- **预览-确认**:松手即调后端算出两块(不改服务器状态),前端把原零件暂时替换为两块预览;`Enter` 提交(后端真正删原件、加两块),`Esc` 还原。
- **切割契约**:`POST /api/cut {id, x1,y1,x2,y2, bleed_mm, offset_mm, commit}` —— 坐标为零件**局部物理像素**(与画布渲染同帧:刀模 bbox 原点);`commit=false` 只算不改 PARTS,返回两块(含相对原零件的偏移);`commit=true` 删原件加两块。
- **参数化切割**:`part_builder.materialize_parametric(part, offset_mm)` 由 `subject_image`(RGBA)反推 BGR+mask→复用 `build_part(offset_mm)` 得到含 image_layer/mask 的零件;再 `cut_part` SDF 切成两块**固定**零件(image_layer + dieline_path,无 subject 字段)。
- **出血**:全局会话 `BLEED_MM`(默认 `geometry.BLEED_MM=1.5`),`POST /api/set_bleed`;前端控件 mm/px。
- 切完两块在画布上**各自错开 ~ 半个白边** 摆放,均为 fixed 零件(走固定渲染分支)。

### Task 1: 后端参数化零件切割(materialize + cut + preview/commit)

**Files:** `app/part_builder.py`(materialize_parametric)、`app/server.py`(/api/cut 重做 + /api/set_bleed + 会话 BLEED_MM)、`tests/test_part_builder.py`、`tests/test_server.py`。

**要求:**
- `part_builder.materialize_parametric(part, offset_mm=None) -> Part`:
  - `si = part.subject_image`(HxWx4 RGBA, R,G,B,A);`bgr = cv2.cvtColor(si[:,:,:3], cv2.COLOR_RGB2BGR)`;`mask = (si[:,:,3] > 0).astype(uint8)*255`;`return build_part(bgr, mask, offset_mm=offset_mm, part_id=part.id)`。(复用 build_part,产出 image_layer/mask/dieline_path,坐标帧=刀模 bbox,与前端渲染一致。)
- `server`:会话 `BLEED_MM = g.BLEED_MM`;`POST /api/set_bleed {bleed_mm}`(>0 校验)→更新、返回;**重做 `/api/cut`**:
  - 入参 `{id, x1,y1,x2,y2, commit}`(bleed/offset 用会话 BLEED_MM/OFFSET_MM)。
  - 取 part;若 `part.subject_outline`(参数化)→ `mp = materialize_parametric(part, OFFSET_MM)`,否则 `mp = part`(已是固定)。
  - `a,b = cut_part(mp, (x1,y1),(x2,y2), bleed_mm=BLEED_MM)`;过滤 None。
  - `commit=true`:`del PARTS[id]`;对每块设 `cx/cy` 由前端后续定位(此处 x/y=0),`PARTS[piece.id]=piece`;返回 `{parts:[part_to_dict...]}`(fixed 形态)。
  - `commit=false`:**不改 PARTS**,仅返回 `{parts:[part_to_dict(piece) for piece in (a,b)]}`(piece 不入库,仅用于预览;part_to_dict 需能对临时 piece 工作——它只读字段,OK)。
  - piece 是 fixed(无 subject_outline)→ part_to_dict 返回 `kind:fixed, image_base64, dieline_path, w, h`。

### Task 2: 前端切割模式(预览-确认交互)

**Files:** `web/index.html`(出血控件)、`web/app.js`。

**要求:**
- **C 键 / 「切割模式」按钮** 切换 `cutMode`;进入时状态提示「切割:选中一个零件,在其上拖一条直线」;退出清理预览。
- 进入 cutMode:禁用对象拖动(`o.lockMovementX/Y=true` 或 selection 限制),但**仍可点选**零件以选中/换目标。
- **拖直线**:在选中零件上 `mouse:down`(记起点,需命中选中零件)→`mouse:move` 画/更新一条 `fabric.Line`(洋红虚线)预览,**不移动零件**;`mouse:up` 记终点。把起止点(画布坐标)换算到**零件局部物理像素**(减去 group 左上、考虑 group 未旋转;若 group 有 angle 需逆旋转——本期切割仅允许对**未旋转(自由角)**零件,若选中的是锁角/已旋转零件,提示「请先解锁角度再切割」并禁止)。
- **结果预览**:`mouse:up` 后调 `/api/cut {commit:false}` 取两块,隐藏原零件,在原位置附近**错开**加入两块预览(fixed 渲染),并显示「Enter 确认 / Esc 取消」。
- **Enter 确认**:调 `/api/cut {commit:true}`,移除原零件数据,正式加入两块(replace 预览),退出本次切割(回到 cutMode 待下一刀或可继续)。**Esc 取消**:移除两块预览,恢复原零件显示。
- **出血控件**:顶部加 bleed 数字输入 + mm/px;改动调 `/api/set_bleed`。
- 坐标换算用物理像素(无 VIEW_SCALE);预览线用画布坐标(屏幕)绘制即可,提交用局部物理坐标。

- [ ] 实现;preview_eval 核验:模拟选中零件→构造 x1..y2 局部坐标→fetch `/api/cut commit:false` 得 2 块→canvas 出现 2 预览;commit:true 后 PARTS/objById 替换为 2 块。
- [ ] 提交 `feat: 前端切割模式(选中→拖线预览→Enter确认/Esc取消)+出血控件`。
